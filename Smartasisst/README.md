# SmartAssist - Módulo de Automatización de APIs

[cite_start]Este es el primer módulo del proyecto **SmartAssist**[cite: 1, 12]. [cite_start]Su función principal es conectarse a servicios externos para consumir e interpretar datos de forma automática[cite: 3, 4].

## Características
- [cite_start]Estructura modular (`main.py` y `api_client.py`)[cite: 38, 39].
- [cite_start]Integración con APIs REST mediante la librería `requests`[cite: 9, 42].
- [cite_start]Procesamiento de respuestas en formato JSON.
- [cite_start]Consulta automatizada de múltiples registros en paralelo.
